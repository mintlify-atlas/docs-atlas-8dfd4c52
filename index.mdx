Kafka Learning is a practical Java reference project that walks you through every major Apache Kafka pattern from first principles. Starting from a bare Confluent Cloud connection, you'll produce and consume messages with raw strings, enforce contracts with JSON Schema and Avro, infer schemas dynamically from live API data, manage topics programmatically with the Admin API, and package everything into a lean Docker image.

## What you'll learn

<Steps>
  <Step title="Connect to Kafka">
    Set up authenticated connections to Confluent Cloud using SASL_SSL/PLAIN credentials loaded from a `.env` file, or connect to a local broker with zero configuration.
  </Step>
  <Step title="Produce and consume messages">
    Send plain string messages, JSON Schema–validated events, and Avro-serialized records. Consume them back with matching deserializers and consumer group configuration.
  </Step>
  <Step title="Work with schemas">
    Define Avro schemas in `.avsc` files, generate Java POJOs with the Maven Avro plugin, integrate with Confluent Schema Registry, and infer schemas dynamically from live API data.
  </Step>
  <Step title="Administer topics and deploy">
    Create and delete topics via the Admin API, verify connectivity, and run the producer on a schedule inside a lightweight Alpine JRE Docker container.
  </Step>
</Steps>

## Key components

| Component | Class | Purpose |
|-----------|-------|---------|
| Connection | `KafkaConnection` | Confluent Cloud SASL_SSL properties |
| Connection | `KafkaLocalConnection` | Localhost broker, no auth |
| Connection | `RegistryConnection` | Confluent Schema Registry auth |
| Producer | `Producer` | Plain string messages |
| Producer | `SchemaProducer` | JSON Schema–validated events |
| Producer | `AvroProducer` | Typed Avro records |
| Producer | `DynamicProductProducer` | Schema-inferred Avro from API data |
| Consumer | `Consumer` | String message consumption |
| Consumer | `SchemaConsumer` | JSON Schema deserialization |
| Admin | `KafkaTopicCreator` | Programmatic topic creation |
| Admin | `KafkaTopicDeleter` | Programmatic topic deletion |
| Service | `AvroSchemaService` | Runtime schema inference |
| Service | `RecordMapper` | JsonNode → GenericRecord mapping |
